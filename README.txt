TRENDPILL SAFE V4 — First App Prototype

This is a working browser prototype of the phone-friendly dashboard built around
the supplied TRENDPILL_BOT_SAFE_V4.mq5.

Open index.html in a browser.

Important:
- This prototype does NOT execute real trades.
- The buttons change the prototype dashboard state only.
- MT5 remains the trading engine.
- The next integration stage is an MT5-to-app bridge/API for live account,
  position, signal and control data.

The dashboard parameters are based on the supplied EA source.
